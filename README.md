# Ciranda

A Ciranda pretende ser uma plataforma digital aberta e federada para conectar catálogos de serviços e redes de apoio às mulheres mantidos autonomamente por cidades e organizações, preservando a origem das informações e a privacidade dos dados. O projeto parte da integração MISM1 + MISM2 (MISM), como base técnica e resultado preliminar para pesquisa e desenvolvimento de uma arquitetura interoperável.

Derivado do [MISM — MISM-Saude-da-Mulher/MISM](https://github.com/MISM-Saude-da-Mulher/MISM), desenvolvido pelo grupo acadêmico.

Projeto em fase inicial e repositório privado.
